# LectureSync AI - Kotlin Multiplatform Study & Lecture Assistant

**Kotlin Multiplatform Contest 2027 Submission | KotlinConf 2027 (Krakow)**

LectureSync AI is a next-generation academic assistant engineered in **Kotlin Multiplatform (KMP)** and powered by **Google Gemini AI**. It bridges the gap between active classroom participation on mobile devices and deep desktop analytical study.

---

## 1. Core Architecture & Multiplatform Reach

LectureSync AI satisfies the Kotlin Multiplatform Contest requirements by delivering native experiences across multiple platforms:

- **Shared Core (`shared/`):** Clean architecture module in pure Kotlin containing domain entities, Gemini AI prompt pipelines, offline SQLDelight local database, and reactive StateFlow streams.
- **Desktop Client (`desktop_javafx/`):** High-productivity desktop application built with Kotlin and **JavaFX (OpenJFX 21)**, designed visually via **Gluon Scene Builder** with an enterprise dark design system.
- **Mobile Client (`mobile_android/`):** High-mobility client designed with **Jetpack Compose**, optimized for one-touch audio capture, whiteboard photograph digitization, and on-the-go spaced-repetition flashcards.

---

## 2. Key Features

1. **Real-time Audio Stream & AI Transcription:** High-fidelity audio recorded via mobile or desktop microphone with live visual waveform and synchronous AI transcription.
2. **Automated Flashcard Extraction:** Key definitions and exam-critical concepts automatically extracted into spaced-repetition study flashcards.
3. **Generative Concept Mind Maps:** Hierarchical semantic nodes generated by Gemini Flash to visualize relationships between lecture topics.
4. **Lecture Q&A Copilot:** Multi-turn conversational interface grounded strictly in the current lecture's transcript.

---

## 3. UI/UX Design System (Figma & Scene Builder)

To ensure an enterprise-grade, non-artificial aesthetic aligned with JetBrains developer tools:
- **Design Tokens:** Pinned 8px spatial grid, semantic color tokens, and typography hierarchy (`figma/design_tokens.json`).
- **Scene Builder FXML:** Modular FXML views styled with modern CSS (`scene_builder/styles.css`) featuring custom dark themes, subtle borders, responsive layouts, and smooth hover micro-interactions.
- **Live HTML Mockup:** An interactive browser mockup available in `figma/preview_mockup.html`.

## 4. Setup and Installation

### Prerequisites
- JDK 21 (Eclipse Temurin recommended)
- Android Studio Ladybug or IntelliJ IDEA Ultimate
- Gluon Scene Builder (for visual FXML editing)

### Running the Desktop Application
```bash
# Clone the repository
git clone https://github.com/AnderUrienGoierri/KOTLIN_CONTEST.git
cd KOTLIN_CONTEST

# Verify JavaFX FXML assets
ls scene_builder/*.fxml

# Open Scene Builder directly to view or edit the UI:
# File -> Open -> scene_builder/main_view.fxml
```

### Running CI Quality Checks
```bash
# Automated tests and verification
./gradlew check
```
