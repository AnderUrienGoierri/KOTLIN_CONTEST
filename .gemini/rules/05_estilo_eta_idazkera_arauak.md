# Estilo eta Idazkera Arauak

Dokumentu honek kodearen garbitasuna, dokumentazio profesionala eta komunikazio estandarrak zehazten ditu.

---

## 1. Kodearen Estiloa (Kotlin Official Code Style)

1. **Izendapen Konbentzioak:**
   - Klaseak eta Interfazeak: `PascalCase` (adib. `LectureSessionViewModel`).
   - Funtzioak eta aldagaiak: `camelCase` (adib. `fetchGeneratedFlashcards()`).
   - Konstanteak: `SCREAMING_SNAKE_CASE` (adib. `DEFAULT_GEMINI_MODEL`).
2. **Dokumentazioa (KDoc):**
   - Klase eta interfaze publiko guztiek KDoc formatuko iruzkinak izan behar dituzte ingelesez.
3. **Formatzaile Automatikoa:**
   - `ktlint` eta `detekt` erabiliko dira estilo-arauak betearazteko.

---

## 2. Emotikonoen Debekua

- Proiektu osoan (fitxategien edukian, kodean, aldagaietan, README fitxategietan, txostenetan eta commit mezuetan) ez da emotikonorik erabiliko.
- Testuinguru formala eta profesionala mantenduko da uneoro.
